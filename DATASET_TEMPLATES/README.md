### 1.2 词汇表字段说明

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| word | VARCHAR(100) | 是 | 手语词汇 | 你好 |
| meaning | TEXT | 是 | 词汇含义 | 用于问候、打招呼 |
| category | VARCHAR(50) | 是 | 分类 | 基础/生活/社会/社交/情感/科技 |
| scene | VARCHAR(50) | 是 | 使用场景 | 日常问候/家庭/饮食/职业/人际/表达 |
| difficulty | INT | 是 | 难度等级 | 1-入门, 2-基础, 3-进阶 |
| description | TEXT | 否 | 词汇描述 | 见面时的友好问候... |
| hand_shape | JSON | 否 | 手型说明 | {"描述":"...", "要点":[...]} |
| position | JSON | 否 | 位置说明 | {"描述":"...", "要点":[...]} |
| movement | JSON | 否 | 动作说明 | {"描述":"...", "要点":[...]} |
| expression | JSON | 否 | 表情说明 | {"描述":"...", "要点":[...]} |
| video_url | VARCHAR(500) | 否 | 视频URL | /uploads/vocabulary/001.mp4 |

### 1.3 分类参考

**按分类 (category)**:
- 基础 - 基本问候、常用词汇
- 生活 - 日常生活相关词汇
- 社会 - 社会交往相关词汇
- 社交 - 社交互动相关词汇
- 情感 - 表达情感的词汇
- 科技 - 科技相关词汇

**按场景 (scene)**:
- 日常问候 - 你好、谢谢、再见等
- 家庭 - 爸爸、妈妈、孩子等
- 饮食 - 吃饭、喝水、水果等
- 职业 - 工作、公司、职业等
- 人际 - 朋友、老师、同学等
- 表达 - 喜欢、讨厌、高兴等

**按难度 (difficulty)**:
- 1 - 入门级，适合初学者
- 2 - 基础级，需要一定基础
- 3 - 进阶级，需要熟练掌握

## 二、词汇视频要求

### 2.1 视频规格

| 项目 | 要求 |
|------|------|
| 格式 | MP4 |
| 分辨率 | 1280x720 或更高 |
| 时长 | 3-10秒 |
| 单个文件大小 | 不超过 50MB |
| 帧率 | 25fps 或 30fps |

### 2.2 命名规范

```
# 命名格式
{词汇ID}_{词汇名称}.mp4

# 示例
001_你好.mp4
002_谢谢.mp4
003_对不起.mp4
```

### 2.3 视频内容要求

1. 手语演示者正面面对摄像头
2. 手部和面部动作清晰可见
3. 背景简洁，无干扰元素
4. 演示完整动作，从开始到结束
5. 动作规范，符合中国手语标准


### 3.2 题目字段说明

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| id | INT | 是 | 题目序号 | 1 |
| type | VARCHAR(20) | 是 | 题目类型 | choice/video |
| content | TEXT | 是 | 题目内容 | 以下哪个手势表示'你好'？ |
| options | JSON | 是 | 选项列表 | ["A. ...", "B. ...", "C. ..."] |
| correct | VARCHAR(10) | 是 | 正确答案 | A |
| video_url | VARCHAR(500) | 否 | 视频题URL | /uploads/test/003.mp4 |
| explanation | TEXT | 否 | 答案解析 | '你好'的手型是... |
| score | INT | 是 | 分值 | 10 |

### 3.3 题目类型说明

- **choice**: 选择题，4个选项
- **video**: 视频题，需要观看视频后选择答案

## 七、提交说明

### 7.1 提交方式

1. 词汇表：CSV 或 Excel 格式
2. 视频文件：打包为 ZIP 或单独上传
3. 其他数据：JSON 格式

### 7.2 提交路径

请将数据文件放置在 `recognition/dataset/` 目录下，或通过其他方式提供给开发人员。

### 7.3 数据校验

提交数据前，请确保：
- 所有必填字段都已填写
- 词汇视频命名与词汇 ID 一致
- CSV 格式文件编码为 UTF-8
- 视频文件格式正确、大小符合要求

如果您有任何问题或需要进一步说明，请随时联系开发人员。
