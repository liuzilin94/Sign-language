# 掌言手语学习平台

## 项目简介

掌言手语学习平台是一个专业的中国手语学习平台，帮助用户学习标准手语、了解方言手语、观看数字人手语演示等。

## 技术栈

- Vue 3
- Vue Router 4
- Pinia
- Element Plus
- Vite
- Sass

## 功能特性

### 18个核心页面
1. **首页** - 功能入口、每日一词、学习任务概览
2. **登录/注册** - 手机号验证码登录
3. **手语词典** - 多维度筛选、词汇列表
4. **词汇详情** - 视频演示、动作分解、学习笔记
5. **方言上传** - 视频上传、审核状态管理
6. **个人学习** - 收藏、生词、笔记管理
7. **背词练习** - 分级词汇、闯关模式
8. **学习任务** - 艾宾浩斯复习
9. **学习测评** - 单元测试、自动评分
10. **数字人演示** - 文本转手语动画
11. **学习数据中心** - 学习日历、统计图表
12. **社区动态** - 发布动态、点赞评论
13. **成就勋章** - 积分、等级、勋章墙
14. **个人主页** - 学习数据、动态管理
15. **手语科普** - 科普文章、视频
16. **系统设置** - 界面设置、账号安全
17. **审核状态** - 方言审核进度
18. **消息中心** - 通知管理

### 全局功能
- AI问答悬浮球（可拖拽）
- 顶部导航栏
- 移动端底部TabBar
- 视频播放器组件

## 安装运行

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```
