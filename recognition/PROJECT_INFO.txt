# 掌言手语 — 中国手语学习与识别平台

## 一、项目架构

```
csl-recognition/
└── recognition/
    ├── front/              # Vue 3 前端 (端口由 Vite 管理)
    ├── models/             # PyTorch AI 模型定义
    ├── data/               # 数据处理与特征提取
    ├── inference/          # 模型推理核心
    ├── config/             # 配置参数
    ├── ui_plus.py          # Flask 后端 + PyQt5 桌面 GUI (端口 5001)
    ├── start_model_service.py  # 模型服务启动器
    ├── train_isolated.py   # 模型训练脚本
    ├── dataset/            # 语料数据
    └── requirements.txt    # Python 依赖
```

## 二、技术栈概览

### 2.1 后端技术栈 (Python)

| 类别 | 技术 | 说明 |
|------|------|------|
| Web 框架 | Flask 3.x | RESTful API 服务 |
| 跨域支持 | Flask-Cors | 前后端分离跨域 |
| 深度学习 | PyTorch 2.7 | CNN-LSTM、BiLSTM、GRU、Transformer |
| 手部检测 | MediaPipe 0.10 | 提取 84 维手部关键点特征 |
| 视频处理 | OpenCV 4.11 | 视频帧读取与处理 |
| 数据处理 | Pandas + NumPy | 数据整理与计算 |
| 训练监控 | TensorBoard | 训练过程可视化 |
| 桌面 GUI | PyQt5 | 独立桌面客户端界面 |

### 2.2 前端技术栈 (Vue 3)

| 类别 | 技术 | 说明 |
|------|------|------|
| 核心框架 | Vue 3 | 组合式 API (`<script setup>`) |
| 构建工具 | Vite 5 | 快速热更新和构建 |
| UI 组件库 | Element Plus 2.6 | 弹窗、表单、轮播等组件 |
| 状态管理 | Pinia 2.1 | 用户信息、学习数据、设置状态 |
| 路由 | Vue Router 4 | SPA 页面导航 |
| HTTP 客户端 | Axios 1.6 | 代理到后端 `/api` |
| 3D 渲染 | Three.js 0.162 | 数字人 3D 手语动画 |
| 图表 | ECharts 5.5 | 学习数据可视化 |
| 样式 | Sass + CSS3 | Scoped 组件样式 |

### 2.3 代理配置

```
前端 Vite (localhost:5173) → /api/* → Flask 后端 (localhost:5001)
```

### 3.4 手语练习 (/practice) — AI 识别核心

技术栈：**Vue 3 + MediaDevices API + Axios + Flask + PyTorch + MediaPipe**

```
┌──────────────────────────────────────────────┐
│ 词条选择                                      │
│  └─ GET /api/vocabulary                       │
│                                              │
│ 模型初始化                                    │
│  └─ POST /api/init-isolated                   │
│     { model_type: 'cnn_lstm' }                │
│                                              │
│ 摄像头权限                                    │
│  └─ navigator.mediaDevices.getUserMedia()    │
│                                              │
│ 录制 3 秒视频                                 │
│  └─ MediaRecorder API                        │
│                                              │
│ 发送识别                                      │
│  └─ POST /api/predict-isolrated               │
│     FormData: { video Blob, target_index }   │
│                                              │
│ 后端处理                                      │
│  ① opencv-python 读取视频帧                  │
│  ② MediaPipe 检测 84 维关键点特征            │
│  ③ PyTorch CNN-LSTM 模型推理                 │
│  ④ 返回置信度和预测结果                       │
│                                              │
│ 前端展示                                      │
│  置信度 > 50% → 判定正确/错误               │
└──────────────────────────────────────────────┘
```

## 四、AI 模型体系

### 4.1 模型文件

```
recognition/models/
├── cnn_lstm_model.py    ← 练习页使用 (默认)
├── bilstm_model.py      # 双向 LSTM + 多头注意力
├── gru_model.py         # 轻量级门控循环单元
├── transformer_model.py # 自注意力机制
└── ensemble_model.py   # 多模型加权融合
```

### 4.2 模型参数

| 参数 | 值 |
|------|------|
| 输入特征 | 84维 (42关键点 x 2只手) |
| 时序长度 | 30帧 |
| 隐藏层大小 | 128 |
| 循环层数 | 2 |
| 输出类别 | 41个手语词汇 |

### 4.3 词汇表 (dataset/corpus.txt)

共 40 个手语词汇，涵盖方位、属性、状态三大类：

| 类别 | 词汇示例 |
|------|----------|
| 方位 | 来、去、到、晒、醒 |
| 属性 | 有、没有、是、不是、属于 |
| 尺寸 | 小、多、少、长、短 |
| 高度 | 高、矮(低)、远、近、宽、窄 |
| 粗细 | 粗、细(细致)、厚、薄 |
| 轻重 | 轻、重、沉重 |
| 软硬 | 硬、软 |
| 深浅 | 深、浅 |
| 快慢 | 快、慢 |
| 温度 | 冷、热(汗)、暖(温暖、暖和) |
| 胖瘦 | 胖(肥)、瘦、饱 |

## 五、Flask API 接口

| 路由 | 方法 | 功能 |
|------|------|------|
| `/api/init-predictor` | POST | 初始化手语识别预测器 |
| `/api/predict-video` | POST | 视频文件手语识别 |
| `/api/predict-webcam` | POST | 摄像头实时手语识别 |
| `/api/init-isolated` | POST | 初始化孤立词预测器 |
| `/api/predict-isolated` | POST | 孤立词视频识别 |
| `/api/predict-isolated-webcam` | POST | 孤立词摄像头识别 |
| `/api/predict-isolated-jpg` | POST | 孤立词 JPG 序列识别 |
| `/api/vocabulary` | GET | 获取词汇表 |

**服务端口**: 5001

## 七、启动方式

### 7.1 前端启动

```bash
cd recognition/front
npm install
npm run dev
# 访问 http://localhost:5173
```

### 7.2 后端启动

```bash
cd recognition
# 方式1: 直接运行 (同时启动 Flask API + PyQt5 GUI)
python ui_plus.py

# 方式2: 后台服务启动器 (仅 Flask API)
python start_model_service.py
# 监听端口: 5001
```
